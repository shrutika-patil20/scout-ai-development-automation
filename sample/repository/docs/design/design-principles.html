PeoplePath · UI foundations

Thoughtful by design.

A small set of design principles and reusable controls for a welcoming, clear, and easy-to-use employee onboarding experience.

Design principles

Use these principles when adding screens or changing existing onboarding flows.

✳

Welcome people warmly

Use human language and friendly details. Keep the interface calm and respectful.

↗

Make the next step clear

Give each task a direct name, a useful detail, and a clear status or due date.

◉

Show progress at a glance

Use consistent progress bars, status badges, and summaries to reduce guesswork.

Aa

Keep it readable

Use generous text sizes, strong contrast, visible focus, and comfortable spacing.

Accessibility and interaction rules

Keep body text at a comfortable size, maintain strong text contrast, and make every action usable by keyboard. Preserve a visible focus ring, use a real label for each field, provide an accessible name for icon-only buttons, and pair color with plain-language status text. Prefer clear confirmation after a user changes onboarding data.
